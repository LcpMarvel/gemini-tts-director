# Kong Yiji — crowd director’s script

Lu Xun · Chinese source, English direction

The crowd makes cruelty sound like entertainment. One patron leads the accusation; two others join a little late and more quietly. Keep a clear main line rather than a synchronized chant.

## Reading

Narrative lead-in followed by three separately generated voices. This is a crowd, so use local scene mixing rather than a native two-speaker take. Repeat only the existing accusation; do not add agreement words.

> 他们又故意的高声嚷道，“你一定又偷了人家的东西了！”
